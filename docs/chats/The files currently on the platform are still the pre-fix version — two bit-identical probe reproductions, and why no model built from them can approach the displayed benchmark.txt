## 3. This is decorrelation, not a scale error — and it cannot be removed by any rescaling

The all-zeros probe pins the target's second moment on the public subset exactly:

`E[y²] = 1.013783458² = 1.027757`.

For any submission `p`, `E[y·p] = (E[y²] + E[p²] − RMSE²) / 2`. For the persistence submission

(`E[p²] = 1.019073` over the full test file) this gives correlation **0.610** with the hidden

targets, and an optimal scale factor `c* ≈ 0.62`.

We then submitted `0.62 × persistence` as an out-of-sample check. Predicted **0.7985**, actual

**0.803528** — the small residual is the public/private subset difference.

The consequence matters more than the number: **the best score obtainable from any scalar multiple

of the distributed `TWS_t` is ≈ 0.8035.** The displayed benchmark, produced by the starter recipe on

v2, is 0.659470066, and three participants independently reproduced 0.899886318 for that same recipe

on the current files. A scale-only defect would be removable by a scalar; this is not.

## 4. What this implies for the leaderboard

Inverting `RMSE = √(E[y²](1 − ρ²))` gives the correlation each score requires:

| Score | Required correlation with the hidden targets |

|---|---|

| 0.659470 (displayed benchmark, v2 starter recipe) | 0.760 |

| 0.623384 (current 3rd place) | 0.789 |

| 0.559588 (current 1st place) | 0.834 |

| 0.886420 (persistence, current files) | 0.610 |

Persistence on the distributed files reaches 0.610. On our own held-out reconstructions of the test

structure, persistence correlates ≈ 0.64–0.71 with the *distributed* targets — so the distributed

features lose roughly 12–15% of their correlation when scored against the hidden ones, consistently

across all forecast horizons, which matches what @shafi_miakhil and @MICADEE reported in July.

Working backwards, a score of 0.6234 from the current files would require correlating ≈ 0.89 with

the distributed targets across a 1-to-7-month horizon mix. Single-month persistence itself only

reaches ≈ 0.80. We do not believe scores in the current top range are reachable from the files being

served today.
